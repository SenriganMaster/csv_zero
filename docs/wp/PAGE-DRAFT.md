# ページ下書き

WordPress の固定ページに貼る文章の下書きです。ツール本体は「カスタムHTML」ブロックに `csv-zero-wp.html` の中身（1行）をそのまま貼ります。REST API やコードエディタで本文ごと送るときは、`<!-- wp:html -->` で包んだ `csv-zero-wp.block.html` を使います。

## タイトル

CSVの先頭の0が消えるのを防ぐ無料ツール｜CSV 0落ち防止コンバーター

（短くするなら「CSVの先頭の0が消えるのを防ぐ」）

## スラッグ

csv-zero

## メタディスクリプション

CSVを、すべてのセルが文字列のExcelファイル（.xlsx）に変換します。先頭の0、1-2の日付化、1234567890123456の指数表記を防ぎます。ファイルはブラウザ内だけで処理し、送信しません。

## 使い方

1. 「ファイル」でCSVを選ぶか、「貼り付け」に表を貼って「変換する」を押します。文字コードと区切り文字は自動で判定します。
2. プレビューで、0001 や 0600000 が元のままかを確かめます。Excelで直接開くと崩れる値は件数で示します。
3. 「Excel用（.xlsx）をダウンロード」を押します。ダウンロードが始まらないときは「保存する」を押してください。CSVとして残すときは「CSV（UTF-8 BOM付き）」を押します。

## よくある質問

### 先頭の0は残りますか？

残ります。金融機関コードの 0001、郵便番号の 0600000、電話番号の 09012345678 のような値を、Excelファイルではすべてのセルを文字列として保存します。表示形式は「@」です。

### 1-2 や 1234567890123456 はどうなりますか？

ExcelでCSVを直接開くと、1-2 は日付になり、1234567890123456 は 1.23457E+15 のように指数表記になることがあります。=SUM(A1) のような値は計算されることがあります。このツールで作った .xlsx では、どれも元の文字のままです。セルは数式にはしません。

### Shift_JISのCSVも読めますか？

読めます。文字コードは UTF-8（BOMの有無どちらも）、Shift_JIS（CP932。① や 髙 も可）、UTF-16 を自動で判定します。EUC-JP は自動では選ばれないので、画面の「文字コード」から手動で指定します。

### ファイルは送信されますか？

送信されません。読み込み、判定、変換、ダウンロード用ファイルの作成は、すべてブラウザの中で行います。サーバーへは送りません。

### どのくらいの大きさまで変換できますか？

入力は 200MB までです。Excelファイルにできるのは、Excelの上限である 1,048,576 行、16,384 列、1セル 32,767 文字までです。それを超えると .xlsx は作れません。その場合も「CSV（UTF-8 BOM付き）」では保存できます。

### MacやiPhoneでも使えますか？

ブラウザだけで動くので、パソコンでもスマートフォンでも、インストールなしで使えます。ただし、ブラウザの `CompressionStream` という機能に対応していない古いブラウザでは .xlsx を作れません。その場合も「CSV（UTF-8 BOM付き）」は使えます。

作った .xlsx の文字列セルは「共有文字列」という形式で保存しています。Mac の Numbers や iPhone のクイックルックで、別の形式（inlineStr）のセルが空欄に見えるという既知の問題があるため、その形式は使っていません。

### CSV（UTF-8 BOM付き）と .xlsx の違いは何ですか？

「Excel用（.xlsx）をダウンロード」がおすすめです。ファイル名は「元の名前_text.xlsx」で、全セルが文字列、1行目は太字で固定表示です。「CSV（UTF-8 BOM付き）」は「元の名前_utf8bom.csv」で、文字コードを UTF-8（BOM付き）にして保存し直します。CSVは「文字列」という型を持てないので、ダブルクリックで開くと先頭の0が消えることがあります。
